User Guide: How to Use This Website

Follow these steps to perform a preliminary site feasibility assessment using the AI-Powered Geospatial Web Platform.

Step 1: Open Site Analysis

Click Site Analysis in the navigation menu, or select Start Site Analysis on the Home page.

Step 2: Select Plot Shape

Select Rectangle, Triangle, Trapezoid, or Irregular Plot according to your site's approximate shape.

Step 3: Enter Plot Measurements

Enter the required length, width, height, or additional measurements shown for the selected shape. All measurements must be in feet. The site area is calculated automatically.

For irregular plots, the current calculation approximates the area using two triangles. Verify the actual area using a survey or appropriate measurement method.

Step 4: Enter Site Location

Enter a recognizable location, such as Hyderabad, Telangana. Click Show Location on Map to locate it on the interactive map. Check that the map marker indicates the intended area.

Step 5: Select Soil Type

Choose the available soil category that best matches your preliminary information. Do not guess soil properties for actual construction; a geotechnical investigation is required.

Step 6: Upload a Site Photograph

Select an image of your site. Use Analyze Uploaded Image to view general image-classification predictions. These predictions do not determine soil strength or foundation safety.

Step 7: Analyze the Site

Click Analyze Site. Review the preliminary recommendation, feasibility score, soil notes, dimensions, foundation suggestions, drainage considerations, and development suitability.

Step 8: Review the Dashboard

Open Dashboard to see the current site's calculated area, selected soil, location, and feasibility score.

Step 9: Review the 2D Site Plan

Inspect the conceptual plot outline, proposed building footprint, entrance, and open-space illustration. It is not a surveyed drawing or construction-ready plan.

Step 10: Generate a Report

Click Generate / Save Report as PDF. In the print window, select Save as PDF if that option is available.

Important engineering notice

This website is an educational preliminary-planning tool. Its feasibility score and suggestions are not professional engineering approval. Do not select or construct a foundation using these results alone. Obtain site-specific soil testing, structural design, survey data, and approval from qualified professionals and relevant authorities.
